# ONE AI — Mobile-first starter prototype

## What this is
A static, mobile-first HTML prototype for an AI-guided job/income planning flow. It works in a phone browser and does not require a computer to try.

## Included
- `index.html` — single-file interface with interactive starter plans.
- This is a prototype, not a live AI service.
- No user data is sent to a server by this file.
- It does not yet include authentication, database, live job listings, AI API, or payments.

## How to test on a phone
1. Extract the ZIP on your phone, if your file app supports it.
2. Open `index.html` with a browser or upload it to a static hosting service.
3. Fill in the form and tap “ကျွန်တော့်အစီအစဉ် ဖန်တီးပေးပါ”.
4. Test the copy button.

## Next production steps
1. Host the static prototype over HTTPS.
2. Add a backend that keeps AI API keys secret.
3. Connect an AI provider and add rate limits/cost controls.
4. Add privacy notice, deletion controls, and safety checks.
5. Test with real users before adding payments or scaling.

Never put private API keys in `index.html`. Do not promise guaranteed jobs or income.
